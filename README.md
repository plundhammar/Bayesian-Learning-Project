# Bayesian Learning: Project
We study the problem of clustering interaction hits produced by overlapping photons in an event-based silicon detector. Using simulated PET-like data, we model pairwise temporal and spatial distances between interactions and apply a simplified Bayesian distance clustering framework. Posterior inference is performed via Gibbs sampling, and uncertainty is summarized through co-assignment probabilities. For a subset of 100 photons, the method recovers the cluster sets with an Adjusted Rand Index of approximately 0.6.
